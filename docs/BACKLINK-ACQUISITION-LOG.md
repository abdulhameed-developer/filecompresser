## Placement verification procedure

For any future accepted placement, record the real public page before counting it. Open the page, verify the destination/anchor and inspect `rel`, redirects, HTTP status and robots/canonical. Save a dated screenshot or HTML-derived link record. A public page and a crawlable page are not proof that Google/Bing indexed it; keep index state unknown until a valid engine observation exists. Check traffic using the stated provider/date, and measure real referrals only if the owner's approved privacy setup can do so. Automatic RUM remains off; no analytics collector was added for this task.

Do not turn an unsuccessful pitch into a series of reminders without a real follow-up purpose. Do not duplicate one article across thirty publications, buy links, swap links or use meaningless comments and profiles.
