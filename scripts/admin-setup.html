FILECOMPRESSER · CONTENT EDITOR

The editor needs its first build.

This is the setup page, not a login form. Hosted administrator sign-in becomes available after TinaCloud is connected and the CMS is built.

  1. In the project folder, run npm run setup:cms.
  2. Run npm run dev:cms to generate and test the local editor.
  3. Follow docs/SEO-AND-HOSTING.md to connect GitHub, TinaCloud and your domain.

The local editor edits files on your computer without a login. Only use it on a trusted machine. Production uses TinaCloud authentication.
